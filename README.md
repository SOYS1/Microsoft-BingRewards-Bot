# Microsoft BingRewards Bot

自动完成 Microsoft Rewards 在必应（Bing）上的每日搜索任务，支持自动点击奖励卡片。

> 中文名：Microsoft Bing Rewards 自动搜索助手 | 英文名：Microsoft BingRewards Bot
> 版本 1.1.1 | 作者 SOYS | 许可 MIT

---

## 功能特性

- **自动搜索**：从页面和侧边栏自动收集搜索词，随机顺序使用，避免重复
- **模拟人工**：搜索间隔随机化、滚动行为随机化，降低被检测风险
- **自动点击奖励卡片**：自动识别并点击每日 +5/+10/+15 积分任务卡片（支持新旧两种 HTML 格式）
- **智能进度监控**：实时读取 Rewards 侧边栏进度，无进度时自动休息，绕过跨域 iframe 限制
- **暗色模式**：自动跟随 Bing 页面主题切换
- **后台运行**：切换标签页不影响搜索进度

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 点击扩展图标 → "添加新脚本"
3. 将 Microsoft-BingRewards-Bot.js 内容粘贴进去
4. 保存（Ctrl+S）

或从 [Greasyfork](https://greasyfork.org/scripts/538825) 直接安装。

## 使用方法

1. 打开 [bing.com](https://www.bing.com) 并登录 Microsoft 账号
2. 页面右下角会出现 **Rewards 自动助手** 面板
3. 点击 **▶ 开始搜索**，脚本自动执行搜索任务
4. 搜索过程中可随时点击 **⏹ 停止搜索** 中断

### 面板说明

| 区域 | 说明 |
|------|------|
| 标题栏 | 显示脚本名称和版本，可拖动面板位置 |
| 进度条 | 实时显示搜索进度（如 30/90） |
| 状态栏 | 显示当前操作状态（搜索中/滚动中/等待中等） |
| 每日任务 | 显示每日奖励卡片的完成状态 |
| 搜索词列表 | 显示当前可用的搜索词来源 |
| 配置参数 | 可折叠的配置区域，调整搜索行为 |
| 开始/停止按钮 | 控制自动搜索的启停 |

- 点击标题栏的 **−** 按钮折叠面板（仅保留进度和状态）
- 点击 **+** 按钮展开完整面板

---

## 配置参数

点击面板中的 **⚙️ 配置参数** 展开配置区域。

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 休息时间(分) | 5 | 连续无进度时的休息时间 |
| 滚动时间(秒) | 10 | 每次搜索后模拟滚动的时长 |
| 等待时间(秒) | 10 | 获取进度后的等待时间 |
| 容错次数 | 3 | 连续多少次无进度后触发休息 |
| 自动点击奖励卡片 | 开启 | 是否自动点击每日奖励卡片 |

> 默认参数已经过优化，不建议随意修改。修改后自动保存到本地存储。

## 工作流程

`
开始搜索（Bing 页面无需保持在前台）
  ↓
获取搜索词（页面 → 侧边栏 → 保底词库）
  ↓
执行搜索（自动提交，页面跳转到搜索结果）
  ↓
脚本在后台持续运行（可切换标签页做其他事）
  ↓
模拟滚动页面（10秒）
  ↓
检查搜索进度（打开 Rewards 侧边栏）
  ↓
进度增加？── 是 → 等待后继续下一次搜索
  │
  否
  ↓
连续无进度次数 ≥ 容错次数？
  ├── 是 → 休息 5 分钟后继续
  └── 否 → 等待后继续下一次搜索
  ↓
搜索次数达到 90/90？
  ├── 是 → 任务完成，自动停止
  └── 否 → 继续循环
`

## 常见问题

**Q: 脚本没有反应 / UI 不出现？**
1. 确认已安装 Tampermonkey 扩展
2. 确认脚本已启用（Tampermonkey 面板中显示绿色开关）
3. 刷新页面（Ctrl+F5 强制刷新）
4. 检查浏览器控制台（F12）是否有报错

**Q: 搜索进度不增加？**
1. 确认已登录 Microsoft 账号
2. 确认 Rewards 积分按钮可见（页面右上角）
3. 脚本会自动重试，耐心等待
4. 如持续不增加，尝试手动点击 Rewards 侧边栏确认

**Q: 切换到其他网页后搜索会暂停吗？**
不会。只要 Bing 搜索页面没有关闭，脚本就会在后台持续运行。

**Q: 如何关闭自动点击奖励卡片？**
展开配置区域 → 取消勾选"自动点击奖励卡片"

**Q: 每日任务显示"加载中"？**
脚本需要打开 Rewards 侧边栏获取数据，如侧边栏无法打开会自动重试，确认页面未被其他弹窗阻挡。

## 技术细节

- **运行时机**：@run-at document-end，DOM 加载完成后执行
- **匹配范围**：*://*.bing.com/*，所有 Bing 页面
- **权限**：@grant none，无需额外权限
- **存储**：使用 localStorage 保存配置和搜索状态
- **兼容性**：支持 Tampermonkey / Greasemonkey 4+
- **跨域处理**：网络请求拦截器绕过跨域 iframe 限制
